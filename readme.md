# p5.js SVG Export Sketch

Dieses Projekt zeigt, wie man mit **p5.js** eine einfache Zeichnung erstellt und diese als **SVG-Datei** exportiert.  
Das Sketch zeichnet einen Kreis in der Mitte des Canvas und ermöglicht es, das Bild durch Drücken der Taste **"s"** zu speichern.  

## Features

- Canvas mit **SVG-Renderer** erstellen (500 × 500 Pixel)
- Einen Kreis im Zentrum zeichnen
- Export der aktuellen Zeichnung als `.svg`-Datei
- Automatischer Dateiname: Zeitstempel + `-out.svg`

## Voraussetzungen

- Browser mit Unterstützung für p5.js
- Die p5.js-Bibliothek und die p5.js-SVG-Renderer-Erweiterung

## Verwendung

- Öffne die HTML-Seite im Browser.
- Ein Kreis wird im Zentrum des Canvas angezeigt.
- Drücke die Taste **"s"**, um die aktuelle Zeichnung als SVG-Datei herunterzuladen.

## Beispiel-Animation

- ⚪ Ein einzelner Kreis in der Mitte des Canvas
- SVG-Datei lässt sich in Vektorprogrammen wie Inkscape oder Illustrator öffnen und bearbeiten
